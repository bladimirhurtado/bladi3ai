# Análisis de datos y métricas
## Flujo
1. Define pregunta, unidad de análisis, población, período y significado de cada métrica.
2. Inspecciona esquema, frescura, faltantes, duplicados, valores atípicos y sesgos de selección.
3. Valida transformaciones, denominadores, zonas horarias y filtros.
4. Usa métodos y visualizaciones apropiados; separa correlación de causalidad.
5. Contrasta resultados con cálculos independientes o controles de plausibilidad.
6. Comunica hallazgos, incertidumbre, limitaciones y recomendación accionable.
## Reglas
No ocultes datos faltantes ni selecciones métricas solo porque favorecen una conclusión. No inventes cifras.
