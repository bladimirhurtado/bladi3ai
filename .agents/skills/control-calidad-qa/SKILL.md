# Control de calidad (QA)
## Flujo
1. Traduce cada requisito a una condición observable y verificable.
2. Prioriza pruebas según impacto: bloqueantes, regresión, seguridad, compatibilidad y usabilidad.
3. Diseña casos positivos, negativos, límites, entradas inválidas y estados de recuperación.
4. Ejecuta las pruebas en el entorno disponible y registra comando, resultado y limitaciones.
5. Separa defectos confirmados, sospechas y mejoras; adjunta pasos para reproducir.
6. Repite las pruebas afectadas después de corregir y confirma que no aparezcan regresiones.
## Reglas
La ausencia de errores visibles no demuestra que todo funcione. Nunca inventes capturas, logs ni resultados.
