# Diseño UI/UX
## Flujo
1. Define usuarios, tarea principal, contexto, plataforma y restricciones de accesibilidad.
2. Inspecciona el diseño existente antes de proponer cambios; conserva elementos útiles.
3. Diseña jerarquía visual, navegación, estados vacíos, carga, error, éxito y recuperación.
4. Comprueba móvil, teclado, foco, contraste, etiquetas, tamaños táctiles y lectura con tecnologías asistivas cuando sea posible.
5. Construye componentes consistentes y estados interactivos funcionales.
6. Valida el flujo con escenarios y, si hay navegador disponible, revisa tamaños de pantalla y errores.
## Reglas
No confundas una maqueta con una interfaz funcional. No sacrifiques accesibilidad por decoración.
