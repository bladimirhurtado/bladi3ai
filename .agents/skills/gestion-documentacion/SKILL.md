# Gestión de documentación
## Flujo
1. Identifica audiencia, propósito, nivel técnico y tarea que debe completar el lector.
2. Verifica el comportamiento descrito contra el código, configuración y pruebas reales.
3. Organiza por tareas: requisitos, instalación, configuración, uso, solución de problemas y mantenimiento.
4. Distingue valores de ejemplo de valores reales; marca requisitos y riesgos.
5. Añade pasos reproducibles, salidas esperadas y enlaces a fuentes oficiales.
6. Revisa enlaces, comandos, nombres de archivos y consistencia tras cambios.
## Reglas
No documentes funciones inexistentes como si estuvieran implementadas. No incluyas credenciales, datos personales ni secretos.
